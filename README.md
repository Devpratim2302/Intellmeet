# IntellMeet

IntellMeet is an AI-powered meeting and collaboration platform that helps teams conduct online meetings, communicate in real time, generate meeting summaries, and manage tasks in one place.

## Features

- **User Authentication:** Secure registration and login.
- **Video Conferencing:** Real-time audio, video, and screen sharing.
- **Meeting Chat:** Real-time messaging and participant presence.
- **AI Transcription:** Convert meeting speech into text.
- **Meeting Summaries:** Generate summaries, key discussion points, decisions, and action items.
- **Task Management:** Organise and track tasks using a Kanban board.
- **Team Workspaces:** Manage workspaces and team members.
- **Notifications:** Receive updates about meetings and tasks.

## Technology Stack

- **Frontend:** React 19, TypeScript, Vite
- **UI and Styling:** shadcn/ui, Tailwind CSS v4
- **State Management and Data Fetching:** Zustand, TanStack Query
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Real-Time Communication:** Socket.io, WebRTC
- **AI Integration:** Gemini
- **Authentication and Security:** JWT, bcrypt
- **File Storage:** Cloudinary, AWS S3
- **Caching and Real-Time Scaling:** Redis
- **Containerisation:** Docker
- **Orchestration:** Kubernetes, Helm
- **CI/CD:** GitHub Actions
- **Monitoring and Error Tracking:** Prometheus, Grafana, Sentry
